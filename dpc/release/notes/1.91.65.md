# 1.91.65

## 工具区

- 统一工具区各单元格的尺寸，工具箱、待办卡与其他工具保持一致。

## 自律与限额

- 每日时间限额的重置时间支持自定义小时和分钟，已放入“设置 → 自律”一级菜单。
- 新增亮屏时间上限。达到自定义的当日亮屏时长后，手机会自动进入灰屏模式。
- 未完成的禁忌卡不再影响时间限额判定，也不会额外增加冻结或罚时。

## 冻结页

- 冻结时段、时间限额和应用明细收进二级页面；首页只保留两类抽象功能入口和当前概况。
- 原页面底部的断网应用设置统一移入右上角设置菜单，页面更简洁。

## 运行状态

- 冻结页顶部可直接进入运行状态子页，逐行查看受管应用及当前冻结状态。
- 延时冻结、打卡罚时、学习联动和热爱卡减免的结束时间统一显示到秒，并跨过接续点时自动刷新。

## 验证

- 完整离线回归通过。
- API 34 模拟器设备检查 29 项通过，覆盖重置时间、亮屏上限、禁忌卡隔离、冻结页两级结构和应用明细。
