# 本地数据、备份与云端配置

备份唯一常规入口：守卫右上角设置 → **数据与备份**。整合备份、目标与打卡旧格式、记忆模块备份、备忘录含附件备份均在这里操作，原打卡、记忆和备忘录中的备份按钮已移除。卡管理 → **打卡设置**保留同步设置 / 上传打卡数据（同步不等于整合备份）。打卡页只留卡片，不放状态行和按钮——同步相关的都归打卡设置。数据与备份页顶部给出当前云端同步状态（已启用 / 已暂停 / 仅本机），打卡设置的「同步设置」行副标题也直接显示同一句状态。

学习记录继续存放在应用私有目录，不需要服务器。此版本新增统一备份和配置入口；WebDAV、GitHub 私有仓库、Git 仅保存配置，尚不执行上传、下载或自动同步。原有 Gist 同步独立保留，是当前真正联网的那一条，因此排在状态行下第一位。

## 整合本地备份（用户数据白名单）

点“导出整合本地备份”，通过系统文件选择器保存 ZIP。包含：

- 目标、打卡台账、每日默认完成量和打卡完成快照；
- 记忆卡、图片、复习记录、题库和答题记录；
- `cards-v1.json` 中的热爱卡、总结卡、券和历史周期记录；
- 笔记、日记、附件、回收站、分类和待办卡；
- 冻结规则与时间格、每日额度、使用限额、断网和页面规则；
- 学习联动、休息提醒、番茄钟默认值、正念记录和未来倒计时；
- 应用语言、内置外观选项、背景图，以及工具栏项目选择。
- 跨设备额度连接设置（不含令牌）、成就提示基线、AI 接口地址与模型（不含密钥）、部署提示已读状态、禁忌罚时计划、页面统计和规则诊断记录。
- 第三阶段本地数据库快照 `database/afs_data.db`，包含应用、规则、时间段、冻结分组、规则版本、专注会话、执行事件、每日统计、迁移记录和本地 Outbox。

备份不包含云端配置及其凭据、AI 服务密钥、局域网访问令牌、解锁码密钥、设备管理授权、首次宽限计时、同步缓存，以及应用私有目录外的自定义字体。备份中的笔记、日记和待办正文按原样保存，不对正文内容做密码识别或删改。ZIP 未加密，应保存在自己的安全位置。它不是系统级全局镜像，恢复只覆盖上述白名单；当前正在运行的计时和通知状态按设计不迁移，但已排定的禁忌罚时计划会保留。

文件包含版本清单、每项大小和 SHA-256。导入拒绝越界路径、重复项、未列入许可清单的文件、不匹配的校验值或不支持的格式版本。大小上限根据当前设备的应用堆上限预留安全预算计算，页面显示实际限制，最大为解压后 128MB；超过限制会停止，可改用各模块的备份工具。

备份格式当前为 v2，读取端兼容 v1。数据库使用一致性快照，不使用直接复制正在写入的 WAL 主文件；导出后会对备份中的数据库执行 `PRAGMA quick_check`。恢复数据库时先关闭 Repository，替换主文件并删除旧的 `-wal` / `-shm`，失败则回滚到恢复前归档。

## 整合恢复

恢复是覆盖操作，会先预览并要求确认。它只允许在未启用设备所有者，或首次配置宽限期内进行，以免通过回放旧备份重置学习、奖励或冻结状态。日常增加内容请使用下方的记忆卡片、题库、笔记导入入口；各模块现有的导入/合并行为不变。

确认恢复后，先把经过校验的备份存入应用私有目录，再重启应用，在学习存储和后台服务初始化前应用恢复。写入前保存原数据回滚包并记录事务标记；写入失败或进程中断会恢复原数据。不会恢复或清除当前设备管理身份，也不会重置首次宽限计时。

旧版备份中没有待办、日记等新增偏好分组时，恢复会保留这些新版本机数据，避免旧备份把新功能内容误清空。备份格式仍为兼容的 v1，新增权限边界由偏好键白名单控制。

恢复完成后保留本机已有云端凭据，但暂停旧版 Gist 同步并切换合并缓存空间，防止恢复后的本地内容自动推向原云端。需要继续 Gist 同步时点「重新启用云端同步」（数据与备份页，或打卡设置 → 同步设置里的「重新启用」）：只清挂起标记，目标、凭据、合并基线都不变，随即补推一次台账；凭据已被清空时才需要重新填 token 验证。新云端配置入口仍只保存配置。

## 上传失败怎么判断

云端状态只在这两处显示，内容一致：数据与备份页顶部的状态行、打卡设置里「同步设置」行的副标题——`已启用 · owner / gist · 上次上传 HH:mm · 云端 rev N`，挂起时是 `已暂停（本地完整恢复后挂起）`。手动上传的两个入口（卡管理 → 打卡设置 → **上传打卡数据**、数据与备份 → **上传打卡数据**）都等一轮完整的同步结束才回报结果，已有同步在跑时不会再被误报成「上传失败”；成功时提示 `已上传 HH:mm · rev N`，N 与本机记录的云端台账版本一致。真失败时会区分「未启用/已暂停」和「网络失败」两种提示。

## 云端配置字段

| 类型 | 地址或目标 | 其他字段 | 凭据 |
|---|---|---|---|
| WebDAV | HTTPS 服务器地址 | 相对目录、用户名 | 应用密码或 token |
| GitHub 私有仓库 | `owner/private-repository` | 分支、相对目录、用户名 | GitHub 访问令牌 |
| Git | HTTPS / SSH / `git@host:path` 仓库地址 | 分支、相对目录、用户名 | HTTP 密码或 token；SSH 密钥接入在传输阶段处理 |

配置可保存和删除。保存不验证服务器连通性、仓库私有性或访问权限，也不标记为已连接；这些检查属于后续传输实现。新配置入口的云端凭据使用 Android Keystore 的 AES-GCM 加密，编辑时留空保留已存凭据，不在界面回显明文。
