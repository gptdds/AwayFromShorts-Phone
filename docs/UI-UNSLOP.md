# 原生界面重构

方向：每日自律手账。安静、明确、有秩序；中性纸白与墨色文字，用户选定的主题色集中用于操作、选中与实际学习内容。

## 统一规格

- 页面边距 20dp；分组间距 24dp；面板内边距 16dp。
- 标题 24sp / 32sp，正文 15sp / 24sp，摘要 13sp / 20sp。
- 卡片默认圆角 12dp，无浮起阴影；导航为不透明中性表面和细边框。
- 工具与导航使用同一套绘制线性图标；工具页移除装饰 emoji。
- 设置长摘要换到标题下方，允许完整换行；短值保持右对齐。
- 数字启用等宽特性，导航选中处使用短刻度；滑动切换使用临界阻尼，去掉玻璃、发光与弹性形变。
- 打卡完成页的热爱入口带页面标题和日期；实际学习、卡片与冻结内容继续承担主要视觉信息。
