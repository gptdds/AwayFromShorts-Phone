# Liquid Glass / Fluid Gradient 组件实验室

更新：1.91.84 已将材质接口接入原生业务页面，具体范围和验证见 `docs/NATIVE-MATERIALS.md`。下文保留首轮独立实验室的设计与验收记录。

本轮只制作独立 Android Demo，正式业务页面尚未迁移。原有简约、空间风格与冻结/额度/学习规则保持原实现。

## 展示与结构

背景固定纯黑，不加载全屏背景图片。顶部切换材质并暂停持续动画；底部切换操作、输入、信息三个组件分组。

| 展示组 | 可操作内容 |
| --- | --- |
| 按钮 | 主操作、重置、增加计数 |
| 卡片 | 大型专注卡与两张指标卡，响应局部触摸 |
| 输入 | 搜索和多行草稿，焦点与输入产生局部光效 |
| 调节 | 弹性滑块开关、可拖动时长滑条 |
| 标签 | 三个可选胶囊 |
| 列表 | 点击选中/取消项目 |
| 导航 | 三个分类，移动且拉伸的选中材质块 |
| 悬浮按钮 | 打开对话框 |
| 浮层 | 可选菜单、保存/取消对话框 |
| 进度 | 共享时长进度与加载指示 |
| 选择器 | 低/标准/高三档 |
| 通知 | 操作结果提示，可关闭 |

## 两种材质

- Glass：冷色透明透镜语言，厚度边缘、色散环境采样、曲面高光、输入凹槽。主按钮、滑块、卡片采用不同材质参数。按压改变局部光学采样并压缩表面，松手弹簧恢复并产生波纹。
- Fluid：组件内部双密度场、噪声扰动、由密度梯度计算光照；卡片和标签边界发生轻微有机变化。按压扰动局部场，松开扩散波。开关与导航选中块具有行程拉伸。
- 图片只作为内部环境光/纹理采样源，不能替代控件轮廓与交互。
- 每个节点只观察原始指针，不消费业务控件事件；业务状态与样式对象分开保存。

## 依赖

`app → feature:componentlab → core:style-api`；两个样式包分别提供自己的参数、材质程序和资源。app 通过注册表装配。风格切换不使用重建页面或复制业务逻辑的方式。

材质解码和编译异步执行；单引擎共享材质资源与绘制时钟。切换/暂停页面释放资源。API 33 以下使用轻量绘制降级，不宣称具有同等折射效果。

## 验证与证据

构建使用 `AFS_UNIVERSE_DEMO=1`，独立包名 `com.afs.guard.universe`。不覆盖正式应用。

- `ComponentLabTest`：黑背景、暂停后的静态组件、按钮计数、标签/选项/列表选中、输入保留、开关/滑条、菜单、对话框和通知。
- `ComponentLabMotionTest`：真机窗口采样，实际按住/拖动/滚动/分类切换；后台资源释放。
- 截图和测试日志：`build/component-lab-evidence/`。
- 录像由应用窗口真实采样帧按采集时间编码，非设计效果视频，不能用其采样帧率代替应用渲染帧率。

## 未达到完整规格的项目

1. Glass 当前折射的是环境纹理，尚未实现对任意背后 UI 内容的实时折射；不是物理光线追踪。
2. Fluid 为程序化密度场和材质动画，不是 Navier–Stokes 流体求解器。
3. 两套组件的布局语义共享，部分外轮廓仍接近；尚需用户视觉验收，不能以测试通过代替审美验收。
4. 此实验室尚未接入原业务页面；没有宣称正式应用所有组件已经改造。
5. 尚未完成持续耗电、温升、低端真机帧时间测试。

## 2026-11-15 实际运行结果

- PLR110 真机：`component-final-phone.log`，3 项测试通过，包括完整组件操作回归、弹窗材质存活、动态窗口采集及退出释放。
- API 34 模拟器：完整组件回归通过；共享 Fluid 生命周期的暂停恢复、降级及清理两项测试通过。
- 模拟器整屏截屏有材质显示异常，不能据此判定真机显示。真机弹窗截屏确认材质正常。主页面使用 PixelCopy；弹窗在确认自身窗口持有焦点后采集整屏。
- Fluid 首轮实际绘制统计：756 帧、54 卡顿帧（7.14%）；CPU 帧耗时中位数 12 ms、P95 17 ms，GPU 中位数 5 ms、P95 5 ms。包含启动后的采样，不是稳定负载基准；尚未达到最终性能验收。
- 真机系统录屏向公共存储及临时目录写文件均返回 Permission denied。本轮交付的是实际应用窗口采样视频，按原始采集时间编码；不能当成手机原生全帧率录像。
- 最新 APK：`build/component-lab-evidence/afs-component-lab.apk`，安装名 AFS Visual Demo，与正式应用并存。
