# 待办卡与学习天数统计（1.91.38）

## 待办卡

守卫首页的 **工具区** 提供 **待办卡** 入口；新建时可只填标题和说明，或另设时间。没有定时的待办立即进入打卡页，设定时间的待办到点才进入打卡页，并由 `TodoReminder` 发送桌面通知。通知使用「待办提醒」高优先级通道；Android 13+ 需要通知权限，页面提供「发送测试通知」和「系统通知设置」入口。通知能否以横幅、锁屏形式显示仍由系统通知设置决定。

打卡页的待办卡：上滑完成，下滑取消；取消会保留在「已处理」里，不删除记录。待办不写打卡目标、记忆或题库进度，不改学习联动，不触发罚时，也不延长冻结。到点只是发出通知并把卡推到打卡页；到期未完成不会产生强制学习或冻结动作。通知点击打开打卡页，页面开着时按到点状态定期刷新；开机、覆盖安装、时区和时钟变化后会补排未发过的提醒。

数据保存在 `afs_todo/todos_v1`，并纳入整合本地备份；恢复后重新协调提醒。`TodoTest` 覆盖排序、到期、JSON 容错和同一提醒不重复弹出。

新建/编辑待办弹窗里有显式的「＋ 添加提醒」入口：点它先弹「添加提醒」说明框，确认后进日期/时间选择器；已设提醒则显示「修改提醒」和「取消提醒」。到点仍发桌面通知并推入打卡页，不完成不影响学习或冻结。

每张待办还可以单独选择提醒铃声：系统默认、任意系统通知铃声或静音，并可在保存前试听。铃声 URI 随待办保存，改时间或延时不会丢失；Android 8+ 为默认、静音及每个自定义铃声使用稳定且独立的通知通道。旧待办没有铃声字段时回退系统默认，不可读取或格式错误的 URI 也不会让提醒失效。到点小窗采用不遮挡整页的紧凑卡片，桌面通知仍按该待办自己的铃声播放。

## 卸载与名单

被管理应用可以随时卸载：守护不再为被管理应用设置卸载拦截，并主动撤销旧版可能留下的全局 `DISALLOW_APPS_CONTROL`。冻结时段、限额格子成员、挂后台计时标记和当天已用时间都按包名保留；重新安装同名应用后继续沿用。移出冻结时段或限额名单、调低分钟数、取消挂后台标记，以及取消共享格子的星期冻结，都只在调整时段（或首次安装宽限期）开放。

调整时段本身也只进不出：非调整时段可以打开选择器查看当前时段，但 `TimeWindow.save` 在保存处拒绝非时段写入，想真正改时段得等进入调整时段；否则把时段改成「现在」就等于绕过所有收紧操作。首次安装宽限期内仍可配置，避免刚装完就被锁死。

冻结应用页的「时间限额」库同样只进不出：非调整时段可以长按拖起应用、拖进额度格子、给未限额应用新建额度；从已有额度格子移出成员、调小分钟数、删格子仍只在调整时段开放。

## 按天统计

- 记忆卡：`MemoryStats.Summary.activeDays` 从复习日志按本地自然日去重，同一天复习任意张卡只计 1 天；未来记录和已删除学科不计入。工具区显示本日队列、今天是否已学习、累计学习天数和连续天数，统计页也显示学习天数。
- 刷题卡：`QuizData.statsDays()` 按 `days` 中 `attempts > 0` 的日期计数，同一天答任意道题只计 1 天；首页显示累计学习天数、本月学习天数和今天是否已学习。今日目标题数、累计正确率与连续练习仍沿用各自原有指标。
