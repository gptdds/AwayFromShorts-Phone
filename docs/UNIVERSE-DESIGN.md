# Universe 代表页面

历史第一轮记录，已被 docs/UNIVERSE-V2-SPEC.md 的重建设计取代；下面的线条背景与无图片阶段不再是当前 Demo 的实现。

范围：设置中的“查看风格效果”共享守卫首页。简约和空间风格保留。业务列表、搜索、筛选、导航、ViewModel 均复用。

Liquid Glass Universe：深墨蓝环境、暖金与珍珠蓝曲面光带；对称悬浮面板、透明层次、窄边高光。按压采用纵向凹陷与弹簧复位，手指作为局部光源，释放扩散单层光波。远景粒子轻微受吸引。

Fluid Motion Universe：深蓝能量场、电蓝/紫罗兰/玫红/熔岩橙/青绿丝带；不对称切角面板、胶囊操作。多频波动产生流动丝带，分层粒子围绕流场旋转；长按改变旋涡中心，释放产生三色能量波。

交互输入只观察 Activity 原事件，不消费点击、滑动或长按。UniverseGesture 只保存视觉坐标与时间；材质、场景绘制分别留在各风格模块。持续时钟复用 VisualResources，暂停/切换立即取消。LOW 和 REDUCED_MOTION 保留静态场景及原生反馈。

用户附件已在会话中作为视觉参考读取，但所给桌面路径在当前磁盘不存在，尚未打包图片素材。assets/visual/liquid-universe 与 assets/visual/fluid-universe 预留独立资产目录。当前几何光带为程序绘制，不能宣称是真实 3D 网格或物理流体。

第二轮：玻璃 Shader 使用手指位置产生局部折射位移、RGB 分离与边缘照明。流体粒子采用有状态速度积分、指数阻尼、局部旋涡力与一次性松手脉冲；拖尾最多 24 点，650ms 消退，取消和暂停会清理。帧间隔上限 50ms，避免后台恢复后的粒子跳跃。绘制路径复用，减少逐帧分配。

2026-11-15 独立 Android 14 模拟器通过 4 项用例：手势取消与拖尾上限、粒子积分与边界/停帧、窗口截图及真实拖动保留页面状态、HIGH 四风格连续切换释放。日志 build/universe-isolated-device.log。窗口截图 build/universe-captures/liquidglass.png 和 fluidgradient.png。共享模拟器曾在测试期间收到安装操作并终止目标进程；这些中断未计为通过。

曲面描边与粒子分布修正后，最终构建再次通过；粒子边界与窗口截图/真实拖动两项复验通过，记录 build/universe-final-check.log 与 build/universe-final-device.log。自查截图确认可读性与风格差异，但丝带仍有程序线条感，距离参考图的有机体积材质尚有差距；未将该差距记为完成。

待验收：真机连续手势、图像纹理采样、手势驱动液态页面转场、旧原生页面推广、真实功耗与帧耗时。当前仅完成代表页面的阶段实现，不作为完整 Universe 交付。RGB 分离是屏幕空间近似，不是真实光线追踪；速度粒子不是物理流体求解器。
